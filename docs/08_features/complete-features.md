# 프로젝트 전체 기능 명세

**관련 문서**: [프로젝트 개요](../01_overview/project-overview.md) | [기능 요구사항](../02_requirements/functional.md)

## 📋 개요

Hamcam은 학습자를 위한 종합 학습 관리 및 협업 플랫폼입니다. 이 문서는 구현된 모든 기능을 상세히 설명합니다.

---

## 🎯 주요 기능 카테고리

1. **인증 및 사용자 관리**
2. **대시보드 및 학습 관리**
3. **커뮤니티 (게시판, 댓글, 공지)**
4. **소셜 기능 (친구, 채팅)**
5. **팀 스터디 (화상 스터디, 퀴즈방)**
6. **평가 및 AI 분석**
7. **AI 학습 계획 생성**

# 1. 인증 및 사용자 관리

## 1.1 회원가입

### 기능 설명
- 새로운 사용자 계정 생성
- 프로필 이미지 업로드 가능
- 학년, 관심 과목, 학습 습관 등 정보 입력

### 입력 항목
| 항목 | 필수 | 설명 |
|------|:----:|------|
| 아이디 | ✅ | 로그인용 고유 ID |
| 비밀번호 | ✅ | 8자 이상 |
| 이메일 | ✅ | 이메일 인증 (향후 구현) |
| 이름 | ✅ | 실명 |
| 닉네임 | ✅ | 표시용 닉네임 |
| 학년 | ✅ | 1-6학년 |
| 관심 과목 | ✅ | 다중 선택 가능 |
| 학습 습관 | ✅ | 아침형/저녁형 등 |
| 전화번호 | ❌ | 선택 입력 |
| 프로필 이미지 | ❌ | 선택 업로드 |

### 검증 규칙
- 아이디 중복 체크
- 이메일 형식 검증
- 비밀번호 최소 8자
- 닉네임 중복 체크

---

## 1.2 로그인

### 기능 설명
- 세션 기반 인증
- 로그인 성공 시 사용자 정보 반환
- LocalStorage에 사용자 정보 저장

### 인증 흐름
```
1. 사용자가 아이디/비밀번호 입력
2. 서버에서 검증
3. 세션 생성 및 Redis 저장
4. JSESSIONID 쿠키 발급
5. 사용자 정보 반환
6. 클라이언트 LocalStorage 저장
```

### 세션 관리
- 세션 저장소: Redis
- 세션 만료: 설정에 따름 (기본 30분)
- 자동 로그인: 쿠키 유효 시 자동 인증

---

## 1.3 회원 탈퇴

### 기능 설명
- 사용자 계정 삭제
- 연관 데이터 처리 (Soft Delete)

### 삭제되는 데이터
- 사용자 프로필
- 작성한 게시글 (Soft Delete)
- 댓글 (Soft Delete)
- 친구 관계
- 채팅 참여 이력

### 보존되는 데이터
- 학습 기록 (통계용)
- 평가 결과 (분석용)

---

## 1.4 프로필 관리

### 조회 가능 정보
- 기본 정보 (이름, 닉네임, 이메일)
- 학습 정보 (학년, 관심 과목, 학습 습관)
- 활동 통계 (누적 포인트, 가입일)

### 수정 가능 항목
- 닉네임
- 학년
- 관심 과목
- 학습 습관

- 프로필 이미지

# 2. 대시보드 및 학습 관리

## 2.1 캘린더

### 기능 설명

### 이벤트 타입
| 타입 | 색상 | 설명 |
|------|------|------|

---

## 2.2 Todo 관리

### 기능
- Todo 생성/수정/삭제
- 날짜별 Todo 조회
- 완료 상태 토글
- 우선순위 설정

### 우선순위
- LOW (낮음): 파랑
- MEDIUM (보통): 노랑
- HIGH (높음): 빨강

### Todo 항목
- 제목 (필수)
- 설명 (선택)
- 날짜 (필수)

## 2.3 시험 일정 관리

### 기능

### 시험 정보

### D-Day 계산
- 오늘 기준 남은 일수

## 6.4 레벨 시스템

### 레벨 단계
- BEGINNER (초급)
- INTERMEDIATE (중급)
- ADVANCED (고급)
- EXPERT (전문가)

### 레벨업 조건
- 초급 → 중급: 70점 이상 2회 연속
- 중급 → 고급: 80점 이상 2회 연속
