# TeamStudy 페이지 UI/UX 개선 설계안 (v3)

## 1. 개요 (Overview)

- **목표:** `/teamStudy` 페이지의 사용자 경험(UX) 및 시각적 디자인(UI)을 전면적으로 개선하여, 최신 디자인 트렌드와 사용자 중심의 기능성을 결합한 새로운 인터페이스를 제공합니다.
- **핵심 컨셉:**
    1.  **클레이모피즘 (Claymorphism):** 카드, 버튼 등 주요 상호작용 요소에 적용하여 부드럽고 친근한 입체감을 부여합니다.
    2.  **구글 SaaS 스타일:** 전체적인 레이아웃, 타이포그래피, 정보 구조에 적용하여 명확성과 사용성을 확보합니다.
    3.  **파스텔 색상:** 주조색으로 부드러운 파스텔 톤을 사용하여 시각적 편안함과 생동감을 동시에 제공합니다.
- **주요 변경점 (v3):** 사용자가 '모아서 보기'와 '분할해서 보기' 두 가지 뷰 모드를 선택할 수 있는 기능을 추가하여, 개인의 학습 탐색 스타일에 맞는 최적의 환경을 제공합니다.

## 2. 레이아웃 및 기능 (Layout & Features)

### 2.1. 뷰 모드 선택 (View Mode Selection)
페이지 상단에 '모아서 보기'와 '분할해서 보기' 두 개의 토글 버튼을 배치합니다.
- **모아서 보기 (Combined View):** 기본값. 모든 스터디방(Focus Room, Quiz Room)이 하나의 목록에 통합되어 표시됩니다.
- **분할해서 보기 (Split View):** 사용자가 선택 시 활성화. 'Focus Room'과 'Quiz Room'이 좌우 두 개의 컬럼으로 나뉘어 표시됩니다.
- **규칙:** 두 버튼 중 하나는 반드시 선택된 상태를 유지합니다.

### 2.2. 모아서 보기 (Combined View) 상세 설계
- **레이아웃:** 단일 콘텐츠 영역에 모든 스터디방 카드가 표시됩니다.
- **컨트롤:** 목록 상단에 **단일 컨트롤 헤더**가 위치하며, 다음 기능을 포함합니다.
    - **검색:** 전체 스터디방 대상 검색창.
    - **필터:** `전체`, `Focus Room`, `Quiz Room` 등 방 종류를 필터링할 수 있는 드롭다운 또는 탭.
    - **정렬:** 최신순, 인기순 등 정렬 기준 드롭다운.
- **페이지네이션:** 목록 하단에 **단일 페이지네이션** 컴포넌트가 적용됩니다.

### 2.3. 분할해서 보기 (Split View) 상세 설계
- **레이아웃:** 화면이 좌우 2단으로 분할됩니다.
    - **좌측 컬럼:** 'Focus Room' 전용 영역.
    - **우측 컬럼:** 'Quiz Room' 전용 영역.
- **컨트롤:** **각 컬럼 상단에 독립적인 컨트롤 헤더**가 위치합니다.
    - **Focus Room 컨트롤:** Focus Room 내에서만 적용되는 검색, 필터, 정렬 기능.
    - **Quiz Room 컨트롤:** Quiz Room 내에서만 적용되는 검색, 필터, 정렬 기능.
- **페이지네이션:** 각 컬럼 하단에 **독립적인 페이지네이션**이 적용됩니다.

## 3. 신규 디자인 시스템 (New Design System)

*(디자인 시스템의 색상, 타이포그래피, 컴포넌트 스타일 등은 이전 설계와 동일하게 유지)*

### 3.1. 색상 팔레트 (Color Palette)
- **Primary (주조색):** `--c-primary: #8AB4F8`
- **Accent (강조색):** `--c-green: #81C995`, `--c-purple: #C58AF9`, 등
- **Neutrals (중립색):** `--c-text-primary: #3C4043`, `--c-surface: #F8F9FA`, 등

### 3.2. 컴포넌트 스타일
- **스터디방 카드 (Claymorphism):** 둥근 모서리, 부드러운 그림자 효과를 유지하여 친근한 느낌을 전달합니다.
- **페이지네이션 컴포넌트:** 숫자 버튼 스타일은 구글 SaaS 디자인 가이드를 따르며, 현재 페이지는 `--c-primary` 색상으로 강조 표시합니다.

## 4. 사용자 경험(UX) 개선

- **선택의 유연성:** '모아서 보기'와 '분할해서 보기'를 제공하여 사용자가 자신의 탐색 스타일에 맞는 뷰를 선택할 수 있습니다.
- **명확한 분리 (분할 모드):** 'Focus Room'과 'Quiz Room'을 시각적으로 분리하여, 사용자가 원하는 학습 유형의 방을 즉시 찾을 수 있도록 돕습니다.
- **통합 탐색 (통합 모드):** 모든 방을 한 번에 보면서 필터링하기를 원하는 사용자에게 편리한 탐색 경험을 제공합니다.
- **개선된 정보 구조:** 각 모드에 최적화된 컨트롤과 레이아웃을 통해 시선 흐름이 자연스러워지고 정보 탐색 효율이 높아집니다.

## 5. 구현 계획 (Implementation Plan)

1.  **전역 상태 추가 (`TeamStudy.js`):**
    - 현재 뷰 모드('combined' 또는 'split')를 관리하는 `viewMode` 상태를 추가합니다. 기본값은 'combined'입니다.
2.  **뷰 모드 토글 컴포넌트 구현:**
    - `viewMode` 상태를 변경하는 버튼 그룹을 구현합니다.
3.  **컴포넌트 구조 조건부 렌더링:**
    - `viewMode` 상태에 따라 '모아서 보기' 레이아웃 또는 '분할해서 보기' 레이아웃을 조건부로 렌더링합니다.
4.  **'모아서 보기' 로직 구현:**
    - API로 가져온 전체 스터디방 목록을 단일 상태 배열(`allRooms`)로 관리합니다.
    - 검색, 필터, 정렬 로직을 `allRooms`에 적용합니다.
    - 단일 페이지네이션 상태(`currentPage`)를 관리합니다.
5.  **'분할해서 보기' 로직 구현:**
    - API로 가져온 전체 스터디방 목록을 `room_type`에 따라 `focusRooms`와 `quizRooms` 두 개의 상태 배열로 분리하여 저장합니다.
    - 각 목록에 대한 독립적인 검색, 필터, 정렬 상태 및 로직을 구현합니다.
    - 각 목록에 대한 페이지네이션 상태(`focusCurrentPage`, `quizCurrentPage`)를 추가합니다.
6.  **재사용 컴포넌트 활용:**
    - `Pagination.js` 컴포넌트는 양쪽 뷰 모드에서 재사용합니다.
    - `RoomCard.js` 컴포넌트도 양쪽 뷰 모드에서 재사용합니다.
    - 검색/필터/정렬 컨트롤을 포함하는 `ControlHeader.js` 컴포넌트를 만들어, '모아서 보기'에서는 한 번, '분할해서 보기'에서는 두 번 재사용할 수 있습니다.
7.  **CSS 스타일 수정 (`TeamStudy.css`):**
    - 각 뷰 모드에 맞는 레이아웃 스타일(Flexbox, Grid)을 추가합니다.
8.  **반응형 디자인:** `@media` 쿼리를 사용하여 모바일 화면에서는 '분할해서 보기' 모드도 1단 구조로 변경되도록 구현합니다.
