## 1. 프로젝트 소개

**Hamcam**은 자기주도 학습의 한계를 보완하고 교육 격차를 완화하기 위해 설계된 학습 관리 및 협업 플랫폼입니다.

### 핵심 가치
- **개인화된 학습 추적**: Face API를 활용한 실제 학습 시간 자동 측정
- **AI 기반 맞춤 학습**: Gemini AI를 통한 학습 계획 생성 및 피드백 제공
- **실시간 협업**: WebRTC P2P 기반 화상 스터디 및 실시간 채팅
- **체계적인 평가**: 2025년 모의평가 기출문제 기반 수학 실력 진단

---

## 2. 개발 배경

### 2.1 현재 문제점

자기주도 학습의 7가지 과제:

| 과제 | 설명 |
|------|------|
| **명확한 목표 부족** | 학습 방향성 설정의 어려움 |
| **시간 관리의 어려움** | 계획적인 학습 시간 배분 실패 |
| **자원 접근 제한** | 양질의 학습 자료 부족 |
| **동기 부족** | 지속적인 학습 의욕 유지 실패 |
| **집중력 문제** | 외부 방해 요소로 인한 집중력 저하 |
| **과도한 부담감** | 학습량에 대한 스트레스 |
| **피드백 부족** | 학습 성과에 대한 즉각적 피드백 부재 |

### 2.2 교육 격차 심화

- 가정·환경·자원 등 외부 요인에 의한 학업 성취도 차이
- 사교육 의존도 증가로 인한 공교육 효과 저하
- 자기주도 학습 능력 격차 확대

## 3. 개발 목표

### 3.1 주요 목표

1. **개인별 학습 추적과 맞춤 피드백**으로 학습 효율 향상
2. **협업 기능**을 통한 문제 해결 능력과 동기 강화
3. **AI 기반 개인화 학습**으로 교육 격차 완화

### 3.2 세부 목표

| 목표 | 구현 방법 |
|------|-----------|
| 실제 학습 시간 측정 | Face API 기반 얼굴 인식 |
| 맞춤형 학습 계획 | Gemini AI 활용 |
| 실시간 협업 학습 | WebRTC P2P 화상 통신 |
| 즉각적인 피드백 | AI 오답 해설 및 학습 분석 |
| 동기 부여 | 팀 스터디 및 경쟁 시스템 |

## 4. 주요 기능

### 4.1 대시보드

| 기능 | 설명 |
|------|------|
| **Todo 관리** | 생성/수정/삭제/완료 토글, 날짜별 조회 |
| **시험 일정 관리** | D-Day 조회, 시험 일정 등록/삭제 |
| **학습 통계** | 전체/과목별/주간/월간 통계 시각화 |
| **목표 설정** | AI 기반 목표 제안 및 수동 업데이트 |
| **학습 시간 측정** | 개인 학습 시간 자동 기록 |
| **AI 회고** | 주간/기간별 학습 회고 생성 |
| **캘린더** | 월별 학습 일정 관리 |

### 4.2 개인 학습

| 기능 | 설명 |
|------|------|
| **Face API 학습 측정** | 실시간 얼굴 감지를 통한 학습 집중도 측정 |
| **자동 타이머 제어** | 얼굴 감지 상태에 따라 학습 타이머 자동 시작/정지 |
| **학습 데이터 저장** | 측정된 학습 시간 백엔드 API를 통해 DB 저장 |
| **단원/시간 설정** | 캠 스터디 시작 전 학습 설정 |

### 4.3 팀 학습

| 기능 | 설명 |
|------|------|
| **스터디방 관리** | 생성/입장/삭제 |
| **퀴즈 풀이방 (QuizRoom)** | 실시간 문제 풀이 및 경쟁 |
| **집중 경쟁방 (FocusRoom)** | 집중 시간 측정 및 순위 경쟁 |
| **실시간 화상 통신** | WebRTC P2P 기반 미디어 스트리밍 |
| **팀 채팅** | 실시간 메시지 송수신 |
| **참여자 상태** | 입/퇴장 실시간 알림 |

### 4.4 수학 문제 평가

| 기능 | 설명 |
|------|------|
| **기출문제 제공** | 2025년 6월, 9월 모의평가 문제 |
| **맞춤형 난이도** | 1-5등급 문제를 학생 수준에 맞게 제공 |
| **실시간 평가** | 즉시 채점 및 피드백 |
| **학습 분석** | 정답률, 소요시간, 약점 분석 |
| **오답노트** | 틀린 문제 자동 수집 |
| **복습 관리** | 복습 시도 기록 관리 |

### 4.5 AI 기반 학습 지원

| 기능 | 설명 |
|------|------|
| **학습 계획 생성** | Gemini AI 맞춤형 학습 계획 자동 생성 |
| **AI 오답 해설** | 단원 평가 후 오답노트 및 피드백 |
| **학습 피드백** | 평가 완료 후 AI 생성 피드백 |

| **성능 분석** | 학습 성과 분석 |
| **맞춤 피드백** | 개인화된 학습 조언 |

### 4.6 커뮤니티

| 기능 | 설명 |
|------|------|
| **게시판 시스템** | 게시글 CRUD, 이미지/파일 첨부, 즐겨찾기 |

| **좋아요 시스템** | 게시글 및 댓글 좋아요 |
| **신고 시스템** | 게시글/댓글/사용자 신고 |
| **차단 시스템** | 사용자/게시글/댓글 차단 |
| **친구 관리** | 요청/수락/거절, 온라인 상태 표시 |
| **실시간 채팅** | 1:1 채팅, 그룹 채팅 |
